# Осколки Разлома — оформление Steam

Комплект оформления профиля Steam в едином стиле dark fantasy / 16-bit pixel art.

## Художественное направление
- Главный мотив: огромный дракон над разрушенным замком.
- Центральный текст: lore мира «Осколки Разлома».
- Палитра: угольно-чёрный, пепельно-серый, багровый, тёмно-фиолетовый, акценты старого золота.
- Графика: 16-bit pixel art, flat colors, crisp edges; без blur и градиентов.

## Структура
- `lore/` — история мира и тексты профиля.
- `design/` — размеры, раскладка и правила оформления.
- `assets/` — подготовленные изображения и исходники.
- `TODO.md` — этапы подготовки и установки.

## Статус
Текстовая спецификация создаётся сейчас. Растровые изображения будут добавлены отдельными файлами после успешной генерации и проверки их размеров.

## Важное ограничение Steam
Произвольный файл нельзя напрямую назначить фоном профиля вместо фона из инвентаря/Points Shop. Файлы artwork предназначены для витрин и других поддерживаемых областей профиля.
