# Размеры изображений Steam

Размеры ниже — целевые размеры подготовки графики для конкретных областей. Перед публикацией проверяйте актуальные требования Steam и предпросмотр выбранной витрины.

| Элемент | Целевой размер / правило | Назначение |
|---|---:|---|
| Аватар | 184 × 184 px | Квадратный портрет; Steam может создавать дополнительные варианты |
| Концепт сцены | 1920 × 1080 px | Рабочий холст для композиции, не обещание прямой загрузки как профильного фона |
| Featured Artwork | 630 px ширина | Одиночная витрина художественной работы |
| Artwork Showcase | основная часть 506 px + боковая 100 px | Составная витрина; учитывать промежуток и обрезку |
| Workshop Showcase | 5 плиток по 150 px | Только если используется соответствующая витрина |

## Подготовка
- Сохранять исходники в PNG.
- Не размещать важный текст у краёв.
- Проверять композицию в предпросмотре профиля.
- Для pixel art использовать масштабирование nearest-neighbor без сглаживания.
- Не добавлять blur, градиенты или полупрозрачные «грязные» ореолы.

**Примечание:** Steam не позволяет произвольно загрузить PNG/JPG и назначить его фоном профиля. Для фонового слота выбирается доступный фон Steam; artwork загружается в поддерживаемые витрины.
