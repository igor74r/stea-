# История мира

Когда-то драконьи империи владели небом, а магия подчинялась законам древних кровавых печатей. После их падения мир не исцелился: пепел закрыл солнце, города ушли под землю, а на границе реальности появилась трещина — Разлом.

Первые кровавые маги создали Кристалл Разлома ценой собственных жизней. Три дракона связали с ним свою сущность и стали живыми печатями. Позднее Кристалл раскололся на три осколка, каждый из которых оказался связан с одним из стражей.

Разлом остаётся закрытым, пока живы все три дракона. Осколки не открывают Разлом: они нужны для стабилизации того, что произойдёт после падения последнего стража.

Мир держится на хрупком равновесии. За трещиной ждёт нечто, чему ещё предстоит дать имя.
